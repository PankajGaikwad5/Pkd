# PKD Studio

Official luxury architecture and interior design portfolio website for PKD Studio.

Designed and developed by **[Pankaj Gaikwad](https://pankajgaikwad.online)** with [DesignNext](https://designnext.co).

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the dev server:
   `npm run dev`
3. Build for production:
   `npm run build && npm start`
